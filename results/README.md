# Validation results

`final_validation_summary.csv` reports pooled metrics on the evaluation points shared by all eight methods after applying the common nonnegative streamflow boundary. Random and continuous-gap scenarios use all common points. H2, H3, and super-long scenarios include both the unfiltered result and a predefined sensitivity row identified by the `excluded_stations` field. The manuscript reports the excluded-station rows for those three scenarios and names the affected stations explicitly.

The corresponding per-point prediction tables are substantially larger and are distributed with the archived analysis outputs rather than this source-code repository.
